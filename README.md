# D&D Character Sheet — V0.3

Prima revisione della V0.1 funzionale del prototipo Monaco.

## Correzioni V0.3
- Navigazione Scheda / Capacità / Equip. / Profilo funzionante
- Ki modificabile con pulsanti + e -
- Uso capacità Ki con finestra protetta dalla SafeArea
- Riposo breve con scelta di più Dadi Vita d8 nello stesso riposo
- Tiri 4d6 spiegati e mostrati in modo più leggibile
- Creazione personaggio riorganizzata graficamente
- Scelta Tradizione: elenco → anteprima → Indietro / Scegli questa Via
- Capacità della sottoclasse attivate nella lista capacità
- Level-up mostra solo le novità del livello raggiunto
- PF al level-up: il tiro d8 viene mostrato prima della conferma
- Salvataggio V0.1 mantenuto tramite la stessa chiave locale

## Contenuti ancora provvisori
Le descrizioni integrali dei manuali, l'equipaggiamento completo e i dati completi delle sottoclassi restano segnaposto finché non vengono verificati sulle fonti fornite.
