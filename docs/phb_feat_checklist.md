# PHB 2014 - checklist talenti

Checklist verificata dei talenti del Manuale del Giocatore 2014.

Ogni talento deve includere:

- ID canonico e definizione univoca;
- nome e descrizione;
- fonte editoriale;
- identità visuale;
- prerequisiti, quando previsti;
- effetti e scelte strutturate;
- collegamento coerente tra chiave, ID e owner.
